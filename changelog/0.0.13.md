# Firstworks 0.0.13

## Bug Fixes & Improvements

- **Common String Tag Compatibility**:
  - Updated the Woven Basket, Cloth, and Rope recipes to use `#c:strings`.
  - Removed duplicate string-specific and twine-specific recipe variants.
- **Harvesting Balance**:
  - Primitive knives now lose one durability when successfully harvesting plant fibre.
  - Primitive knives now lose one durability when guaranteeing raw ochre harvesting.
  - Creative-mode players no longer generate plant fibre from grass and ferns.
- **Assets**:
  - Updated the dough item texture.
- Added regression coverage for common-string recipes and harvesting safeguards.
