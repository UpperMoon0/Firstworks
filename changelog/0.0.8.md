# Firstworks 0.0.8

## Highlights & New Features

- **Standing Torch**:
  - Added a tall primitive **Standing Torch** block with custom 3D model, textures, light level 14, floor survival checks, and animated flame/smoke particles.
  - Solid 16 px base collision with full 26 px outline selection.
  - Shaped crafting recipe (Torch + Stick + Primitive Binding: Crude Cordage / Rope) and `#minecraft:mineable/axe` integration.

- **Barrel Fluid Storage Refactor (Input / Output Separation)**:
  - Split Barrel fluid storage into separate **input** and **output** tanks that share one 4000 mB capacity (`inputFluid + outputFluid <= 4000`).
  - Recipes consume only the fluid they require; leftovers remain in the input store instead of requiring all-or-nothing exact quantities.
  - Recipe fluid outputs write strictly to the output store without contaminating input fluids.
  - Strict output-first fluid removal: bucketing when output fluid is present drains output first; an empty output store drains input.
  - Shift + empty-hand on an open Barrel retrieves the stored input ingredient stack.
  - Automatic migration from legacy single-tank NBT to input tank on world load.

- **Sided Automation Capabilities**:
  - **Top Face (`UP`)**: Input item slot & input fluid tank (fill and drain input).
  - **Bottom Face (`DOWN`)**: Finished item output slot & finished fluid output tank (extraction / drain only).
  - **Sides (`HORIZONTAL` / `null`)**: Combined item & fluid access (fill input, drain output-first then input).
  - Both item and fluid automation remain locked while the Barrel is sealed.

- **Rain Collection**:
  - Optional natural rain collection for open Barrels (`rainFillsBarrels`, default `false`; rate via `rainFillAmount`).
  - Fills input store directly during precipitation via `Block#handlePrecipitation` (respects roof coverage, rain vs. snow, scales with `randomTickSpeed`).
  - Blocked during active processing or pending KubeJS cancellation.

- **Brick Mold Molding Board / Base**:
  - Added a 1 px wooden molding board base to the Brick Mold block model and voxel shape (`NORTH_SHAPE`), providing a reliable center click target and grounded appearance.

- **Dynamic Leather Crafting Override**:
  - Dynamic runtime recipe rewriting replacing the vanilla $2 \times 2$ 4-rabbit-hide $\rightarrow$ Leather crafting recipe with `firstworks:raw_hide`.
  - Fully governed by `replaceAnimalLeatherDrops` config option: if set to `false`, vanilla / datapack / KubeJS recipes are left completely untouched.

- **Modded Wood & Tree Bark Compatibility**:
  - `Firstworks.registerWoodType()` dynamically binds custom logs to the shared `WoodTypeRegistry` and generates bark textures from `logTexture`.
  - Automatic conventional discovery for modded logs/stems/hyphae (`_log`, `_wood`, `_stem`, `_hyphae`, `bamboo_block`).
