# Firstworks 0.0.11

## Added

- Bone and Flint Knives for fibre gathering, hide scraping, and low-yield renewable fleece harvesting.
- Nine-slot, automation-capable Woven Basket.
- Physical charcoal mounds made from connected world logs and configurable sealant blocks; carbonization replaces logs with physical `CharcoalPileBlock` structures in the world.
- Physical Charcoal Pile block (`firstworks:charcoal_pile`) storing 1–4 charcoal with layered voxel shapes.
- Animated in-world Mortar & Pestle workstation with data-driven grinding recipes, KubeJS schema support, and JEI integration.
- Raw Ochre, Ground Ochre, Charcoal Powder, and Copper Fasteners.
- Public `#firstworks:charcoal_igniters` tag and Mortar KubeJS start/completion events.
- Dedicated Jade integrations:
  - `MortarProgressProvider`: displays empty state, loaded materials, ready-to-grind prompt, grinding progress bar with remaining time, and ready output.
  - `CharcoalMoundProvider`: displays active mound log count, seal countdown progress bar, carbonization progress, and expected yield (resolving through visible sealant shell).
  - `CharcoalPileProvider`: displays stored charcoal count on physical charcoal pile blocks.
- Data-driven animal material tags:
  - `#firstworks:drops_bones`
  - `#firstworks:no_bone_drops`
  - `#firstworks:leather_drops_as_raw_hide`
  - `#firstworks:no_raw_hide_drops`

## Changed & Improved

- **Charcoal Mound Diegetic Feedback & Materialization**:
  - Replaced floating item entity drops on mound completion with in-world physical `CharcoalPileBlock`s placed bottom-up.
  - Reworked feedback to be audio-visual and diegetic (ignition flame/smoke burst, sealed "whumpf" dirt thud, seeping smoke during carbonization, and dramatic breach bursts).
  - Capped carbonization smoke emissions to 1–3 plumes/sec to eliminate server and network overhead.
  - Candidate detection calculates shell coverage ratio ($\ge 50\%$), ensuring ordinary trees pass through to vanilla flint-and-steel without false claim.
  - Deferred 1-tick seal confirmation protecting against claim/protection mod placement event cancellations.
  - Upgraded JEI Charcoal Mound instructions to dynamically read from config (log limits, seal window, carbonization duration, and normal/breach yield percentages).
  - Backward compatibility: automatically converts legacy `READY` mounds into charcoal piles upon chunk load.
- **Configuration**:
  - Switched `FirstworksConfig` from `COMMON` to `SERVER` config type (`serverconfig/firstworks-server.toml` / `defaultconfigs/firstworks-server.toml`) to ensure server authoritative values synchronize to connected multiplayer clients.
- **Mortar & Pestle Visuals**:
  - Corrected pestle aspect-ratio UV mapping in `MortarBlockEntityRenderer` to prevent texture stretching on non-square faces.
- **Item Textures**:
  - Removed opaque white/checkerboard backgrounds from all 64x64 item textures (`bone_knife`, `flint_knife`, `charcoal_powder`, `copper_fasteners`, `raw_ochre`, `ground_ochre`).
- **Gameplay Balancing**:
  - Primitive precision work now requires knives instead of accepting combat swords.
  - Animal bone drops are now owned by Firstworks and configurable independently.
  - Raw-hide replacement is restricted by entity-type tags rather than applying broadly to every `Animal` instance.
  - Default bone drops now cover vertebrate animals and exclude squid, glow squid, bees, allays, and undead horses.
