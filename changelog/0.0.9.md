# Firstworks 0.0.9

## Bug Fixes & Improvements

- **Modded Wood & Tree Bark Stripping Compatibility**:
  - Replaced the overly restrictive NeoForgeDataMaps.STRIPPABLES query in GameplayEvents.collectBarkWhenStripping with a simulated block query lock.getToolModifiedState(state, context, ItemAbilities.AXE_STRIP, true) running at LOWEST event priority.
  - Added support for event-level modifications (event.getFinalState() != state), allowing all modded logs (including *Regions Unexplored* and mods registering stripping via block methods or events) to drop custom tree bark upon axe stripping.
  - Expanded conventional client texture discovery in TreeBarkTextureManager to match _wood and _hyphae blocks in addition to _log and _stem.
