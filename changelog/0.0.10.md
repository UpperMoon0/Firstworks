# Firstworks 0.0.10

## Bug Fixes & Improvements

- **Tree Bark Stripping Hardening**:
  - Replaced the unconditional oak fallback in gameplay with WoodTypeRegistry.tryResolveWoodType(), preventing non-wood blocks that support AXE_STRIP (such as modded painted pillars or decorative blocks) from dropping tree bark.
  - Retained the oak visual/default fallback solely in WoodTypeRegistry.resolveWoodType() for tooltip and fallback model contexts.

- **Deterministic Texture Discovery**:
  - Hardened dynamic bark texture discovery in TreeBarkTextureManager with strict priority ordering (_log > _stem > _wood > _hyphae).
  - Added fallback texture candidate resolution so blocks using log textures without providing individual wood textures are resolved reliably without skipping the wood type.

- **Testing & Continuous Integration**:
  - Added unit test suite WoodTypeRegistryTest for conventional and explicit wood type resolution.
  - Added GitHub Actions pull request CI workflow (.github/workflows/ci.yml) to validate build and test execution prior to merging.
