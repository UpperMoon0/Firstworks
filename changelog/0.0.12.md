# Firstworks 0.0.12

## Added

- Saddle Quern: a visible, stroke-driven Stone Age workstation for larger grinding batches.
- Rotary Quern: a Copper Age upgrade with continuous crank-driven processing, larger throughput, persistent progress, and animated rotation.
- Data-driven `firstworks:quern_grinding` recipes with independent saddle-stroke and rotary-duration tuning.
- JEI category, Jade status, NeoForge item automation, and KubeJS starting/completion events for both Querns.
- Flour and initial bulk wheat/ochre grinding recipes.

## Changed

- Progression now distinguishes precision Mortar grinding, bulk Saddle Quern work, faster Rotary Quern processing, and later Create Millstone automation.
